# Public numerical evidence

[Public results](https://github.com/Peneplain/dl/blob/main/docs/report/results/public-results.json) supplies the numeric arrays used by the report. [Source manifest](https://github.com/Peneplain/dl/blob/main/docs/report/results/public-source-manifest.json) records SHA-256 hashes of the original evidence and the derivation code. [Demonstration videos](https://github.com/Peneplain/dl/blob/main/docs/report/videos/README.md) illustrate selected recorded trials.

- `generator_comparison` contains the shared 100-scene ARDY/Kimodo summaries, response arrays in explicit seed order, and 200 trial rows. Every trial includes response time, tracking RMSE, outcome, threshold/retention flags and its original report SHA-256.
- `controller_confirmation` contains all 128 scheduled origins, 124 complete end-to-end pairs, the 54/74 success counts, 25 rescues and 5 harms, the original exact paired McNemar result, the paired-origin bootstrap interval, accounting and scheduled-origin missing-outcome bounds. Bounds and confidence intervals have separate keys.
- `selected_training` contains model configurations, hyperparameters, supervision counts and the complete native numeric epoch histories: 19 Risk epochs and 45 Residual epochs. The retained checkpoints are epochs 7 and 33. Objective components and denominators remain separate numeric fields.
- `invocation_study` contains the 20-origin same-weight selective/always-on comparison, per-origin outcomes, call counts and recorded latency summaries. Both learned modes retain full structured Risk conditioning.

Success rates and effects use fractions unless a field explicitly ends in `_pp`; multiply fractions by 100 for percentages or percentage points. Response times are seconds, tracking errors are radians, and latency fields ending in `_ms` are milliseconds. Epoch curves are recorded means without smoothing. Source hashes identify original bytes; the public JSON files are derived views with new schemas and their own hashes. Publication does not add trials or recompute inferential results.
